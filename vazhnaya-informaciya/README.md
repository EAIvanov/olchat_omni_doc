# Важная информация

Перед установкой и настройкой приложения Олчат ОМНИ внимательно ознакомьтесь с информацией ниже.

## Прогрев аккаунта

{% hint style="warning" %}
Если вы подключаете новый номер, обязательно прогрейте его в течение 7–10 дней перед использованием в Олчат ОМНИ.
{% endhint %}

В период прогрева используйте аккаунт только через официальное мобильное приложение и веб-версию:

* Ведите обычные личные переписки.
* Подписывайтесь на каналы, ставьте реакции и пишите комментарии.
* Постепенно добавляйте контакты небольшими порциями.

Не подключайте новый аккаунт к Олчат ОМНИ сразу после регистрации. Это существенно повышает риск ограничений или блокировки.

{% hint style="warning" %}
Избегайте модифицированных версий приложения, покупки «разблокировок» и автоматизированного спама.
{% endhint %}

#### Особенности работы с МАКС

Принципы безопасной работы аналогичны Telegram:

* Рекомендуется прогрев нового аккаунта в течение 7–10 дней.
* Соблюдайте умеренность при первых контактах.
* Избегайте шаблонных массовых сообщений.

#### Особенности работы с Telegram

* Номер телефона в Telegram по умолчанию не является публичным. Многие пользователи скрывают его в настройках конфиденциальности. Предпочтительнее писать пользователям первым по имени пользователя (@nickname), а не по номеру телефона.
* Telegram строго ограничивает отправку сообщений новым контактам, особенно при резком росте активности.
* Рекомендуется добавлять контакты постепенно и избегать массовых рассылок на начальном этапе.

## Риски блокировки

Олчат ОМНИ работает через пользовательский аккаунт. Это означает, что Telegram и МАКС могут применить ограничения или блокировку при обнаружении признаков автоматизации, спама или резких скачков активности.

**Мы настоятельно рекомендуем**:

* Соблюдать правила мессенджеров.
* Избегать массовых рассылок.
* Не превышать разумные лимиты сообщений.
* Использовать сервис ответственно.

При блокировке аккаунта восстановление зависит исключительно от политики [Telegram](../blokirovka-nomera/blokirovka-v-telegram.md) или [МАКС](/broken/pages/EYJaIzW4hyrjH1X8tfG2).

{% hint style="info" %}
Для минимизации рисков используйте оба канала связи (Telegram + МАКС). Это позволит сохранять связь даже при временных ограничениях.
{% endhint %}
