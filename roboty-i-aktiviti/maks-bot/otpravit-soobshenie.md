# Отправить сообщение

Отправить сообщение — робот, который отправляет текстовое сообщение пользователю МАКС.

### Настройка робота

1. Добавьте робота.

Откройте конструктор бизнес-процессов CRM Битрикс24 и добавьте \[МАКС Бот] Отправить сообщение.

2. Заполните параметры.

* Линия — подключённая линия МАКС Бота.&#x20;
* ID чата / Телефон — укажите числовой ID чата. Несмотря на название поля, номер телефона для этого канала не используется.
* Сообщение — текст отправляемого сообщения.
* Публиковать в чате открытой линии? — Входящим сообщением, исходящим сообщением или без публикации.
* Оператор диалога — по правилам Открытой линии или запускающий робота.
* Создавать Дело со статусами доставки в таймлайне? — по умолчанию включено.

3. Запустите бизнес-процесс.

Сохраните настройки и запустите бизнес-процесс на нужной сущности CRM.&#x20;

### Результат

Сообщение поступает пользователю. В дополнительных результатах доступны Отправлено и ID сообщения.

### Особенности и ограничения

Бот не может начать личный диалог первым: пользователь должен предварительно написать боту.
