# Создать диалог в ОЛ

Робот **\[Олчат ОМНИ] \[МАКС] Создать диалог в ОЛ** позволяет создать новый чат в Открытой линии для клиента. При создании чата при необходимости можно добавить служебное сообщение.&#x20;

## Настройка робота

Для добавления робота перейдите в **Роботы → Создать → Выбор стадии → Другие роботы → \[Олчат ОМНИ] \[МАКС] Создать диалог в ОЛ → Добавить**.

<figure><img src="../../../.gitbook/assets/image (523).png" alt=""><figcaption></figcaption></figure>

После добавления нажмите кнопку **Изменить** на роботе, чтобы открыть окно настройки:

1. **Выберите линию.**\
   Укажите открытую линию (канал) Олчат ОМНИ, в рамках которой будет создан диалог.
2. **Тип идентификатора.**
3. **ID чата/ Телефон.**

<figure><img src="../../../.gitbook/assets/image (764).png" alt=""><figcaption></figcaption></figure>

Остальные настройки можно оставить по умолчанию. Нажмите кнопку **Сохранить**.

Робот можно использовать в сценарии, когда необходимо автоматически начать диалог с клиентом МАКС из CRM:

1. Робот **\[Олчат ОМНИ] \[МАКС] Создать диалог в ОЛ** создаёт диалог в выбранной Открытой линии.
2. Из дополнительных результатов первого робота можно получить **ID диалога**.
3. Полученный ID можно использовать в следующих действиях автоматизации.

## Настройка активити

<figure><img src="../../../.gitbook/assets/image (535).png" alt=""><figcaption></figcaption></figure>

Настройка активити практически идентична настройке робота:

1. **Выберите линию.**\
   Укажите открытую линию Олчат ОМНИ.
2. **Тип идентификатора.**\
   Укажите номер или идентификатор клиента (поддерживаются переменные).
3. **ID чата/ Телефон.**
4. **Дополнительные параметры**:
   * Текст служебного сообщения.
   * Ответственный.

После заполнения нажмите кнопку **Сохранить**.
