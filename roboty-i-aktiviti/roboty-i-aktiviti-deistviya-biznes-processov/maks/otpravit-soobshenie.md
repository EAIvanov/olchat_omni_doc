# Отправить сообщение

Робот «\[Олчат ОМНИ] \[МАКС] Отправить сообщение» позволяет автоматически отправлять текстовые сообщения в мессенджер МАКС из карточек CRM (системы управления взаимоотношениями с клиентами), бизнес-процессов и роботов Битрикс24.

{% hint style="info" %}
Переменная \{{Телефон\}} / \{{Контакт: Телефон\}} / \{{Компания: Телефон\}} или \{{Телефон (текст)\}} / \{{Контакт: Телефон (текст)\}} / \{{Компания: Телефон (текст)\}} собирает и передаёт номера всех типов.
{% endhint %}

Если в робот передаётся массив номеров или текстовая строка с несколькими номерами, отправка будет выполнена на первый номер в списке, на котором зарегистрирован аккаунт в МАКС.

## Настройка робота

Для отправки сообщения добавьте робота «\[Олчат ОМНИ] \[МАКС] Отправить сообщение»: **Роботы → Создать → Выбор стадии → Другие роботы → \[Олчат ОМНИ] \[МАКС] Отправить сообщение → Добавить**.

<figure><img src="../../../.gitbook/assets/image (570).png" alt=""><figcaption></figcaption></figure>

Выполните настройку робота:

1. Укажите линию МАКС, через которую будет выполняться отправка.
2. В поле **Номер телефона** укажите номер получателя.\
   Рекомендуется использовать переменную \{{Телефон (текст)\}} (выбирается через меню «…» напротив поля). Это обеспечит корректную подстановку номера из любого телефонного поля карточки.
3. Введите текст сообщения.
4. Остальные параметры можно оставить по умолчанию. Нажмите **Сохранить**.

<figure><img src="../../../.gitbook/assets/image (1100).png" alt=""><figcaption></figcaption></figure>

## Настройка активити (действия) бизнес-процесса

<figure><img src="../../../.gitbook/assets/image (1) (1) (1) (1).png" alt=""><figcaption></figcaption></figure>

В бизнес-процессе добавьте действие «\[Олчат ОМНИ] \[MAX] Отправить сообщение» и настройте те же параметры, что и для робота:

* Линию МАКС.
* Номер телефона (рекомендуется \{{Телефон (текст)\}}).
* Текст сообщения.

<figure><img src="../../../.gitbook/assets/image (1101).png" alt=""><figcaption></figcaption></figure>

## Особенности&#x20;

В МАКС номер телефона клиента может быть скрыт настройками конфиденциальности. В этом случае:

* Поиск и отправка по номеру телефона могут не сработать.
* Робот вернёт ошибку, что аккаунт не найден или доставка не удалась.

Выбирайте тип идентификатора **По ID чата** и указывайте числовой [ID чата](../../../voprosy-i-otvety/rabota-s-chatami/kak-dat-ssylku-na-konkretnyi-chat.md). Его можно взять из существующего диалога Открытой линии или из интерфейса приложения Олчат ОМНИ.
