# Ожидание ответа

Действие **\[Олчат ОМНИ] \[МАКС] Ожидание ответа** позволяет дождаться ответа пользователя на ваше сообщение. Ответ пользователя содержится в дополнительных результатах робота.

## Настройка робота

Для добавления робота перейдите в **Роботы → Создать → Выбор стадии → Другие роботы → \[Олчат ОМНИ] \[МАКС] Ожидание ответа → Добавить.**

<figure><img src="../../../.gitbook/assets/image (755).png" alt=""><figcaption></figcaption></figure>

Параметры настройки:

1. **Линия коннектора** — выберите линию Олчат ОМНИ.
2. Тип идентификатора
3. **ID чата/Номер телефона в международном формате.**
4. **Тип совпадения** — поле задаёт правило, по которому робот проверяет входящее сообщени&#x435;**.**
   1. **Любое сообщение** — срабатывает при получении любого входящего сообщения.
   2. **Только текст.**
   3. **Только медиа.**
   4. **Ключевое слово.**
   5. **Регулярное выражение** — -- шаблон, с помощью которого робот проверяет текст входящего сообщения по заданным правилам.
5. **Паттерн** — ключевое слово, регулярное выражение или значение, которое возвращает кнопка в сообщении.
6. Остальные параметры можно оставить по умолчанию.
7. Нажмите **Сохранить**.

<figure><img src="../../../.gitbook/assets/image (758).png" alt=""><figcaption></figcaption></figure>

## Настройка активити (действия) бизнес-процесса

Для использования в бизнес-процессах добавьте действие **«\[Олчат ОМНИ] \[МАКС] Ожидание ответа»**.

<figure><img src="../../../.gitbook/assets/image (609).png" alt=""><figcaption></figcaption></figure>

**Параметры настройки активити:**

1. **Линия коннектора** — укажите линию Олчат ОМНИ.
2. **Тип идентификатора**.
3. **ID чата / Телефон:** введите значение для поиска.
4. Тип совпадения.
5. Паттерн.
6. Остальные настройки оставьте по умолчанию. Нажмите **Сохранить**.

<figure><img src="../../../.gitbook/assets/image (612).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
Чтобы дождаться ответа пользователя и использовать отправленный им ответ в дальнейших сценариях автоматизации, статус или стадия сущности, в которой запущен робот, не должна изменяться. При перемещении на другую стадию робот завершит свою работу и не среагирует на ответ пользователя.
{% endhint %}

Если вы хотите получать ответ пользователя вне зависимости от статусов или стадий, используйте функционал бизнес-процессов. Также следует помнить о том, что для одной сущности вы можете запустить не более 2-х бизнес-процессов одновременно. Подробнее в статье от Битрикс24 [Ограничение на запуск процессов](https://helpdesk.bitrix24.ru/open/5671433/).
