# Редактировать сообщение

Робот и активити **\[Олчат ОМНИ] \[МАКС] Редактировать сообщение** позволяют изменить текст ранее отправленного сообщения в МАКС с помощью автоматизации Битрикс24..

Например, с помощью действия можно автоматически изменить ранее отправленное клиенту сообщение после смены статуса заказа, подтверждения оплаты или получения новых данных.

## Настройка робота

1. Перейдите в **Роботы** → **Создать** → выберите нужную стадию.
2. В разделе **Другие роботы** найдите **\[Олчат ОМНИ] \[МАКС] Редактировать сообщение** и нажмите **Добавить**.
3. На добавленном роботе нажмите **Изменить**, чтобы открыть параметры.

<figure><img src="../../../.gitbook/assets/image (954).png" alt=""><figcaption></figcaption></figure>

Параметры настройки:

1. **Линия.**
2. **ID чата / Телефон.**
3. **ID сообщения.**
4. Остальные параметры можно оставить по умолчанию.
5. Нажмите **Сохранить**.

<figure><img src="../../../.gitbook/assets/image (982).png" alt=""><figcaption></figcaption></figure>



## Настройка активити (действия) бизнес-процесса

В конструкторе бизнес-процесса добавьте действие приложения **\[Олчат ОМНИ] \[МАКС] Редактировать сообщение**.

<figure><img src="../../../.gitbook/assets/image (1002).png" alt=""><figcaption></figcaption></figure>

* Заполните обязательные поля:
* **Линия коннектора.**
* **ID чата/Телефон.**
* **ID сообщения.**
* Сохраните действие.
