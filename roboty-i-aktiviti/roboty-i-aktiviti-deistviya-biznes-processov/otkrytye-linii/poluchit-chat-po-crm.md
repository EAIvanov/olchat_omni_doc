# Получить чат по CRM

Робот **\[Олчат ОМНИ] \[ОЛ] Получить чат по CRM** позволяет получить ID чата Открытой линии, привязанного к сущности CRM (сделке, лиду, контакту или компании).

Полученный ID чата можно использовать в последующих роботах и действиях бизнес-процессов, для которых требуется идентификатор чата Открытой линии.

### Особенности работы

* Робот работает с чатами Открытых линий любых коннекторов, независимо от подключённого мессенджера.
* Если к одной сущности CRM привязано несколько чатов разных коннекторов или Открытых линий, робот возвращает **ID чата, в котором последней была активность**.
* Для поиска чата можно использовать текущую сущность CRM или указать другую.

### Настройка робота

Добавьте робот **\[Олчат ОМНИ] \[ОЛ] Получить чат по CRM** в автоматизацию Битрикс24.

<figure><img src="../../../.gitbook/assets/image (1048).png" alt=""><figcaption></figcaption></figure>

Заполните параметры:

* **Тип сущности** — выберите сущность CRM, для которой необходимо найти чат Открытой линии:
  * **\[не установлено]** — значение по умолчанию.
  * **Текущая сущность** — сущность CRM, в которой выполняется робот.
  * **Сделка** — поиск чата по сделке.
  * **Лид** — поиск чата по лиду.
  * **Контакт** — поиск чата по контакту.
  * **Компания** — поиск чата по компании.
* **ID сущности** — укажите идентификатор сущности CRM, для которой необходимо получить чат. Если робот должен работать с текущей сущностью, оставьте поле пустым.

После заполнения параметров нажмите **СОХРАНИТЬ**.

### Результаты выполнения

После выполнения робот возвращает следующие данные:

| Поле                | Описание                                      |
| ------------------- | --------------------------------------------- |
| **Найден**          | `Y` — чат найден.                             |
| **ID чата**         | Идентификатор найденного чата Открытой линии. |
| **Кол-во диалогов** | Количество диалогов, возвращённое роботом.    |
| **ID диалога**      | Идентификатор найденного диалога.             |

### Особенности работы

Робот получает ID чата Открытой линии, привязанного к указанной сущности CRM.

**Робот работает с любыми Открытыми линиями и коннекторами**, независимо от того, через какой мессенджер ведётся переписка.

Если к одной сущности CRM привязано несколько чатов разных Открытых линий или коннекторов, робот возвращает **ID чата, в котором последней была активность**.

Например, если клиент общался через Telegram и МАКС, робот вернёт ID того чата, в котором активность была позже, независимо от коннектора и Открытой линии.
