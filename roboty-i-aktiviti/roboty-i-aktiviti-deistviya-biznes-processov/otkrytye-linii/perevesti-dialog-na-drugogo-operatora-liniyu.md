# Перевести диалог на другого оператора/линию

Робот **\[Олчат ОМНИ] \[ОЛ] Перевести диалог на другого оператора/линию** позволяет автоматически перенаправить диалог Открытой линии на другого оператора или на другую линию.

{% hint style="info" %}
Робот не отправляет сообщения клиенту. Он выполняет служебное действие — передаёт диалог указанному оператору или линии.
{% endhint %}

## Настройка робота

Добавьте робота так: **Роботы → Создать → Выбор стадии → Другие роботы → \[Олчат ОМНИ] \[ОЛ] Перевести диалог на другого оператора/линию → Добавить**.

<figure><img src="../../../.gitbook/assets/image.png" alt=""><figcaption></figcaption></figure>

Заполните параметры:

1. **ID диалога** — укажите идентификатор диалога Открытой линии, который необходимо перенаправить.
2. **ID пользователя или ID линии** — укажите ID оператора или линии, на которую необходимо перевести диалог.
3. **Запускать от имени** — выберите сотрудника, от имени которого будет выполняться робот.

Нажмите **СОХРАНИТЬ**.

<figure><img src="../../../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>

Робот возвращает следующие дополнительные результаты:

* **Успешно** — результат выполнения робота. При успешном выполнении возвращается значение `Y`.
* **Текст ошибки** — текст ошибки, если робот завершился с ошибкой.
* **Код ошибки** — код ошибки.
* **На какое время остановить процесс** — дополнительный результат робота, доступный для использования в дальнейшей автоматизации.

## Настройка активити

В бизнес-процессе добавьте действие \[Олчат ОМНИ] \[ОЛ] **Перевести диалог на другого оператора/линию.**

<figure><img src="../../../.gitbook/assets/image (804).png" alt=""><figcaption></figcaption></figure>

&#x20;Настройте те же параметры, что и для робота:

* **ID диалога** — укажите идентификатор диалога Открытой линии, который необходимо перенаправить.
* **ID пользователя или ID линии** — укажите ID оператора или линии, на которую необходимо перевести диалог.
* **Запускать от имени** — выберите сотрудника, от имени которого будет выполняться робот.
