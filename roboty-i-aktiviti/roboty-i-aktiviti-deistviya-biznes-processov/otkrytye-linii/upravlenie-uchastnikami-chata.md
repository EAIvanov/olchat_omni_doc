# Управление участниками чата

Робот **\[Олчат ОМНИ] \[ОЛ] Управление участниками чата** позволяет добавить сотрудника Битрикс24 в существующий чат Открытой линии или удалить его из чата.

## Настройка робота

Добавьте робота так: **Роботы → Создать → Выбор стадии → Другие роботы → \[Олчат ОМНИ] \[ОЛ] Управление участниками чата → Добавить**.

<figure><img src="../../../.gitbook/assets/image (835).png" alt=""><figcaption></figcaption></figure>

Заполните параметры:

1. [**ID чата**](upravlenie-uchastnikami-chata.md#id-chata) — укажите идентификатор чата, в котором необходимо изменить состав участников.&#x20;
2. **Пользователь** — выберите сотрудника Битрикс24, которого необходимо добавить в чат или удалить из него.
3. **Действие** — выберите, что необходимо сделать с указанным пользователем:
   * **Добавить** — добавить пользователя в участники чата.
   * **Удалить** — удалить пользователя из участников чата.
4. **Запускать от имени** — выберите пользователя Битрикс24, от имени которого будет выполнен робот.

После настройки нажмите **СОХРАНИТЬ**.

<figure><img src="../../../.gitbook/assets/image (837).png" alt=""><figcaption></figcaption></figure>

### ID чата&#x20;

Идентификатор можно передать из результатов ранее выполненного робота.

Например, сценарий может состоять из двух роботов:

1. [**\[Олчат ОМНИ\] \[МАКС\] Создать диалог в ОЛ**](../maks/sozdat-dialog-v-ol.md) создаёт диалог и возвращает его ID.
2. **\[Олчат ОМНИ] \[ОЛ] Управление участниками чата** получает этот ID и добавляет нужного сотрудника в созданный чат.

В поле **ID чата** второго робота выберите значение из результатов первого робота.

## Настройка активити

В бизнес-процессе добавьте действие **\[Олчат ОМНИ] \[ОЛ] Управление участниками чата.**

<figure><img src="../../../.gitbook/assets/image (844).png" alt=""><figcaption></figcaption></figure>

Настройте те же параметры, что и для робота:

1. **ID чата**.
2. **Пользователь**.
3. **Действие**:
   * **Добавить** — добавить пользователя в участники чата.
   * **Удалить** — удалить пользователя из участников чата.
4. **Запускать от имени**.

После настройки нажмите **СОХРАНИТЬ**.
