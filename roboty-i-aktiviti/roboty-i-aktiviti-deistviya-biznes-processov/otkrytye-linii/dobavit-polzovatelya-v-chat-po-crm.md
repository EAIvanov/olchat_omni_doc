# Добавить пользователя в чат по CRM

Робот **\[Олчат ОМНИ] \[ОЛ] Добавить пользователя в чат по CRM** добавляет выбранного сотрудника в чат, связанный с текущей сущностью CRM.

{% hint style="info" %}
Сущность CRM — сделку, лид, контакт или компанию — робот получает автоматически из карточки, на которой запущен бизнес-процесс.
{% endhint %}

## Настройка робота

Добавьте робота так: **Роботы → Создать → Выбор стадии → Другие роботы → \[Олчат ОМНИ] Добавить пользователя в чат по CRM → Добавить**.

<figure><img src="../../../.gitbook/assets/image (915).png" alt=""><figcaption></figcaption></figure>

Заполните параметры:

* **Пользователь** — выберите, кого необходимо добавить в чат.
* **Запускать от имени** — выберите сотрудника, от имени которого будет выполнено действие.

После настройки сохраните робота.

<figure><img src="../../../.gitbook/assets/image (926).png" alt=""><figcaption></figcaption></figure>

## Настройки активити

В бизнес-процессе добавьте действие \[Олчат ОМНИ] \[ОЛ] **Добавить пользователя в чат по CRM.**

<figure><img src="../../../.gitbook/assets/image (931).png" alt=""><figcaption></figcaption></figure>

Настройте те же параметры, что и для робота:

* **Пользователь** — выберите участника, которого необходимо добавить в чат.
* **Запускать от имени** — выберите сотрудника, от имени которого будет выполнено действие.

<figure><img src="../../../.gitbook/assets/image (936).png" alt=""><figcaption></figcaption></figure>
