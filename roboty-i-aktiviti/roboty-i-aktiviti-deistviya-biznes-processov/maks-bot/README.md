# МАКС Бот

**МАКС Бот** — канал в приложении Олчат ОМНИ для работы с ботами мессенджера МАКС через Битрикс24.

## Основное назначение

С помощью МАКС Бота можно получать сообщения клиентов в Открытых линиях, отправлять сообщения и файлы, использовать интерактивные кнопки, запрашивать контактные данные и геолокацию, а также управлять группами МАКС.

### Задачи роботов

* Автоматизировать отправку различных типов контента: текстовых сообщений, файлов, контактов и геолокации.
* Создавать интерактивные меню и обрабатывать нажатия кнопок.
* Ожидать и обрабатывать ответы пользователей.
* Управлять сообщениями: редактировать, удалять, закреплять и пересылать.
* Получать информацию о чатах, группах, участниках и боте.
* Автоматизировать коммуникации через МАКС и снижать ручную нагрузку на сотрудников.

## Доступные роботы МАКС Бота

В Олчат ОМНИ доступно 25 роботов. Они позволяют автоматизировать отправку сообщений, обработку ответов, управление сообщениями и группами.

#### Отправка сообщений и файлов

1. **\[МАКС Бот] Отправить сообщение** — отправляет текстовое сообщение пользователю МАКС.
2. **\[МАКС Бот] Отправить файл** — отправляет файл по ссылке, из Битрикс24.Диска или из поля CRM.
3. **\[МАКС Бот] Интерактивное меню** — отправляет сообщение с интерактивными кнопками для выполнения различных действий.
4. **\[МАКС Бот] Сообщение с кнопкой-ссылкой** — отправляет сообщение с кнопками для перехода по указанным ссылкам.
5. **\[МАКС Бот] Отправить контакт** — отправляет карточку контакта пользователю МАКС.
6. **\[МАКС Бот] Отправить геолокацию** — отправляет точку на карте по заданным координатам.
7. **\[МАКС Бот] Открыть мини-приложение** — отправляет сообщение с кнопкой для открытия мини-приложения внутри МАКС.

#### Запрос данных и обработка ответов

8. **\[МАКС Бот] Запросить контакт** — отправляет пользователю кнопку для предоставления контактных данных.
9. **\[МАКС Бот] Запросить геолокацию** — запрашивает у пользователя его местоположение.
10. **\[МАКС Бот] Подтвердить нажатие кнопки** — подтверждает обработку нажатия интерактивной кнопки и позволяет показать пользователю всплывающее уведомление.
11. **\[МАКС Бот] Ожидание нажатия кнопки** — ожидает нажатия интерактивной кнопки и продолжает бизнес-процесс после выполнения условия ожидания.
12. **\[МАКС Бот] Ожидание ответа** — ожидает ответ пользователя и продолжает бизнес-процесс при получении сообщения, соответствующего заданным условиям.

#### Управление сообщениями

13. **\[МАКС Бот] Редактировать сообщение** — изменяет текст ранее отправленного сообщения.
14. **\[МАКС Бот] Удалить сообщение** — удаляет сообщение бота у участников чата.
15. **\[МАКС Бот] Закрепить сообщение** — закрепляет выбранное сообщение в чате.
16. **\[МАКС Бот] Переслать сообщение** — пересылает сообщение в другой чат или группу МАКС.

#### Информация о чате и управление группами

17. **\[МАКС Бот] Информация о чате** — получает сведения о чате, включая название, описание и информацию об участниках.
18. **\[МАКС Бот] Список участников группы** — получает список участников группы МАКС.
19. **\[МАКС Бот] Снять администратора** — предназначен для снятия прав администратора с участника группы.
20. **\[МАКС Бот] Удалить участника** — удаляет указанного пользователя из группы.
21. **\[МАКС Бот] Открепить сообщение** — снимает закрепление сообщения в группе.
22. **\[МАКС Бот] Изменить группу** — изменяет название или иконку группы.
23. **\[МАКС Бот] Индикатор печати** — показывает участникам группы, что бот печатает сообщение.
24. **\[МАКС Бот] Покинуть группу** — позволяет боту выйти из группы МАКС.

#### Информация о боте

25. **\[МАКС Бот] Информация о боте** — получает имя, username, идентификатор и статус подключённого бота.

## Рекомендации по использованию

* **Бот не может написать первым.** Чтобы начать переписку, клиент должен самостоятельно отправить сообщение боту в МАКС.
* **Отправка выполняется по ID чата.** Отправка сообщений по номеру телефона через роботов МАКС Бота не поддерживается.
* **Для работы с группами** бот должен быть добавлен в соответствующую группу МАКС. Для отдельных действий ему необходимы права администратора.
* **Для личных и групповых чатов используются разные идентификаторы.** ID личного чата — положительное число, ID группы — отрицательное. ID пользователя и ID чата не являются взаимозаменяемыми.

{% hint style="warning" %}
После включения канала на портале необходимо переустановить роботов, чтобы они появились в конструкторе бизнес-процессов.
{% endhint %}
