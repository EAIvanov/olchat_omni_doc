# Отправка сообщений из мобильного приложения Битрикс24

Если вы работаете с мобильным приложением Битрикс24, то с помощью Олчат ОМНИ (МАКС и Telegram) вы также можете писать сообщения первыми клиентам.

## **Как отправить сообщение**

1. Перейдите в нужную сущность CRM (сделка, лид, контакт или компания).
2. Нажмите на **+**.
3. Выберите пункт **СМС**.
4. В списке выберите **Олчат ОМНИ**.
5. Укажите нужный канал (МАКС или Telegram), если у вас подключено несколько аккаунтов.
6. Введите текст сообщения и нажмите отправить.

{% hint style="info" %}
Для корректной работы убедитесь, что в карточке клиента правильно заполнен номер телефона (для МАКС) или username / ID (для Telegram).
{% endhint %}

### Особенности первой отправки в МАКС по номеру телефона

В виджете отправки для всех порталов доступна пробная отправка текста по номеру телефона через личный аккаунт МАКС.

#### **Логика работы виджета**

* Если с клиентом уже существует диалог Открытой линии — он всегда имеет приоритет. Доступны обычная отправка и кнопка «Открыть диалог».
* Если диалога нет, но в карточке CRM указан телефон — появляется действие **Попробовать отправить**. Кнопка становится активной только после ввода текста.
* Предварительный поиск номера больше не блокирует попытку отправки. Окончательный результат определяется фактическим ответом МАКС.
* При успешной отправке автоматически создаётся диалог Открытой линии. Сообщение отражается в нём один раз, телефон передаётся в Битрикс24.
* После объединения лидов (или других сущностей) существующий диалог линии остаётся приоритетным. Приложение не пытается заново связать номер телефона с внутренним идентификатором чата.

## Работа при временных ограничениях МАКС

Временные ограничения МАКС не блокируют линию полностью.

Что происходит:

* Показывается компактное предупреждение: **«Ограничения МАКС · первым писать не рекомендуется»**.
* В уже существующие диалоги можно отвечать как обычно.
* Без существующего диалога можно попробовать отправить **только текст** по номеру телефона.
* Файлы и голосовые сообщения недоступны до появления подтверждённого диалога.
* Автоматический повтор отправки при неизвестном результате не выполняется.
* Если на номере действительно нет аккаунта МАКС — отображается сообщение «На номере не найден аккаунт МАКС».
* Если подтверждение статуса не пришло вовремя — текст сохраняется, отображается «Статус не подтверждён».

#### **Важные моменты**

Временные ограничения повышают риск отказа при первой отправке. Решение — отправлять или нет — остаётся за пользователем. Если МАКС отклонит сообщение, виджет покажет фактическую ошибку.

Поиск пользователя по номеру может не сработать, если номер скрыт настройками конфиденциальности МАКС (даже если номер виден в приложении на телефоне).

Входящие сообщения при временных ограничениях работают корректно.

## Краткие правила доступности отправки в МАКС

* Есть существующий диалог Открытой линии → отправка доступна всегда.
* Есть только номер телефона, аккаунт не подтверждён и диалога нет → можно ввести текст и нажать «Попробовать отправить».
* После объединения CRM-сущностей → используется существующий диалог линии.
