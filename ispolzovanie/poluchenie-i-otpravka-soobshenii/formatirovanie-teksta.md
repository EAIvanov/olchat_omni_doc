# Форматирование текста

Приложение Олчат ОМНИ поддерживает форматирование текста сообщений в соответствии с возможностями каждого подключённого канала. Форматирование позволяет делать сообщения более читаемыми и выразительными: выделять важное, создавать списки и т. д.

{% hint style="warning" %}
Не все виды форматирования поддерживаются одинаково во всех мессенджерах. Рекомендуем проверять отображение в целевом канале.
{% endhint %}

## Оформление сообщений

### Выделение текста жирным шрифтом

Разместите текст между символами \*\* (звёздочки (одна или две) с обеих сторон).

**Пример:** \*\*Текст жирным шрифтом\*\* → **Текст жирным шрифтом.**

### Выделение текста курсивом

Разместите текст между символами \_ (подчёркивание с обеих сторон).

**Пример:** \_Текст курсивом\_ → _Текст курсивом._

### Написание зачёркнутым текстом

Разместите текст между символами \~\~ (две тильды с обеих сторон).

**Пример:** \~\~Зачёркнутый текст\~\~ → ~~Зачёркнутый текст.~~

### Написание моноширинным шрифтом/в виде блока кода

* Для строчного (inline) кода используйте один обратный апостроф \`.
* Для многострочного блока кода используйте три обратных апострофа \`\`\`.

### Оформление текста в виде блока кода

Для строчного (inline-) кода используйте один обратный апостроф \`. Для многострочного блока кода используйте три обратных апострофа.

### Списки

#### Маркированный список

Для создания маркированного списка используйте символ - (минус) в начале каждой строки.

**Пример:**

```
- Первый пункт.
- Второй пункт.
- Третий пункт.
```

#### Нумерованный список

Для создания нумерованного списка используйте цифры с точкой в начале каждой строки.

**Пример:**

```
1. Первый пункт.
2. Второй пункт.
3. Третий пункт.
```

## Отображение сообщений в чате

Все примеры форматирования будут отображаться в соответствии с правилами конкретного мессенджера. Служебные символы (\*, \_ и др.) при этом не показываются — видно только само оформление.

### **Рекомендации**

* Тестируйте сообщения перед отправкой массовой рассылки.
* Комбинируйте разные виды форматирования (например, **жирный +&#x20;**_**курсив**_).
* В некоторых каналах доступны дополнительные возможности, такие как скрытый текст (спойлер) или гиперссылки.
