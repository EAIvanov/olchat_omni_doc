# Возможности Олчат ОМНИ

Олчат ОМНИ подключает Telegram и МАКС к Битрикс24, а также расширяет стандартные возможности Открытых линий.

Часть инструментов доступна бесплатно сразу после установки приложения. Для работы с Telegram и МАКС предусмотрены дополнительные возможности, которые можно протестировать в течение бесплатного демо-периода, а затем использовать по платному тарифу.

## Бесплатные возможности

После установки Олчат ОМНИ при наличии активной подписки на Маркетплейс Битрикс24 становятся доступны дополнительные инструменты для работы с Открытыми линиями.

{% hint style="info" %}
Для использования этих инструментов не нужно подключать коннекторы Telegram и МАКС или оплачивать тариф Олчат ОМНИ.
{% endhint %}

#### Шаблоны сообщений в Открытых линиях

[Шаблоны](vozmozhnosti/shablony-soobshenii.md) позволяют быстро отправлять заранее подготовленные сообщения прямо из чата Открытой линии.

Доступные возможности:

* Использование шаблонов для типовых ответов клиентам.
* Автоматическая подстановка данных из карточки CRM, например имени клиента, названия сделки или данных компании.
* Настройка доступа сотрудников к шаблонам.

#### Управление чатом Открытой линии

Дополнительные инструменты помогают быстрее находить информацию о чате и связанных с ним сущностях CRM.

Доступные возможности:

* Быстрый переход к прикреплённым карточкам CRM.
* Просмотр информации об Открытой линии, коннекторе и чате в едином окне.

#### Бот-помощник Олчат

[Бот-помощник](vozmozhnosti/bot-pomoshnik.md) позволяет автоматизировать отдельные действия при работе с чатами Открытых линий.

Доступные возможности:

* Настройка названия чата по шаблону с использованием данных CRM.
* Передача параметров аналитики в поля CRM.
* Передача управления чатом другому боту.

#### Роботы для управления Открытыми линиями

В Олчат ОМНИ доступны роботы для автоматизации работы с чатами Битрикс24 без подключения коннекторов Telegram и МАКС.

Подробнее вы можете ознакомиться с роботами [здесь](https://app.gitbook.com/s/ip7Cm0PbTheOQs0EQQ2d/roboty-i-aktiviti).

## Платные возможности

Для работы с Telegram и МАКС через Олчат ОМНИ необходимо подключить соответствующие коннекторы.

Подключение коннекторов открывает дополнительные возможности для переписки с клиентами, управления чатами и автоматизации коммуникаций в Битрикс24.

#### Работа с Telegram и МАКС

* Получение и отправка сообщений через Открытые линии Битрикс24.
* Отправка первого сообщения клиенту из карточки CRM.
* Работа с личными и групповыми чатами.
* Работа с каналами и форумами.
* Отправка и получение файлов и голосовых сообщений.

#### Расширенные инструменты Открытых линий

* **Шаблоны и шорткоды** — дополнительные инструменты для подготовки и отправки сообщений, включая рандомизатор текста для рассылок.
* **Статусы сообщений** — просмотр статусов отправки, доставки и прочтения.
* **Голосовые сообщения** — запись, отправка и прослушивание голосовых сообщений прямо в чате, а также их расшифровка.
* **Управление чатами** — дополнительные действия с диалогами и участниками групповых чатов, включая инкогнито-режим.

#### Интеграция с CRM

* Отправка сообщений непосредственно из карточек CRM.
* Виджет Олчат ОМНИ для создания нового чата или перехода к существующему диалогу.
* Проверка доступности клиента в подключённом мессенджере.
* Работа с перепиской, связанной с лидами, сделками, контактами и компаниями.

#### Автоматизация и рассылки

* Дополнительные роботы и действия бизнес-процессов для работы с Telegram и МАКС.
* Автоматическая отправка сообщений на разных стадиях CRM.
* Создание диалогов и управление участниками чатов.
* Ожидание ответа клиента и выполнение последующих действий.
* Рассылки через CRM-маркетинг.
* Интеграция через REST API.

### Бесплатный демо-период

После установки Олчат ОМНИ можно протестировать возможности подключения мессенджеров без оплаты.

Демо-период активируется автоматически при подключении первой линии. В течение пробного периода доступны возможности приложения для тестирования.

После его завершения для продолжения работы с подключёнными мессенджерами потребуется оплатить соответствующую лицензию.

При этом бесплатные инструменты для управления Открытыми линиями остаются доступны без оплаты тарифа Олчат ОМНИ при соблюдении условий их использования.

Подробнее о стоимости и условиях оплаты — в статье [**Тарифы**](https://docs.olchat.ru/omni/tarify-prilozheniya/tarify).
