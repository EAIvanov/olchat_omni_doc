# Максимальный размер вложения

Максимальный размер файла во вложении — **100 МБ**.

Ограничение действует как при отправке файлов непосредственно из чата Открытой линии, так и при использовании робота **Отправка файла**.

Файлы размером более 100 МБ не отправляются.

{% hint style="warning" %}
При отправке нескольких файлов одним сообщением их **общий размер также не должен превышать 100 МБ**.
{% endhint %}
