# Отправка сообщений через функционал СМС

Олчат ОМНИ позволяет использовать стандартный интерфейс отправки СМС в Битрикс24 для отправки сообщений в Telegram и МАКС. Это удобно для быстрой отправки из карточек CRM (системы управления взаимодействия с клиентами), таймлайна, рассылок через CRM-маркетинг, роботов и бизнес-процессов.

{% hint style="info" %}
Олчат не отправляет настоящие СМС. Сервис регистрируется в Битрикс24 как СМС-провайдер и перенаправляет сообщение в выбранный мессенджер (Telegram или МАКС) по номеру телефона клиента.
{% endhint %}

{% hint style="warning" %}
Мы не рекомендуем использовать эту возможность для регулярной переписки. Он предназначен в первую очередь для:&#x20;

* отправки уведомлений,
* ссылок на оплату,
* автоматических рассылок через CRM-маркетинг,
* роботов и бизнес-процессов.

Для полноценного общения рекомендуем использовать чаты открытых линий, виджеты Олчат, мобильное приложение или специализированные роботы Олчат.
{% endhint %}

Если необходимо отключить СМС-провайдера для конкретной линии, обратитесь в поддержку Олчат.

## **Особенности и ограничения**

1. Можно отправлять только текст до 200 символов.
2. Получатель определяется автоматически по номеру телефона из карточки CRM. Если клиент с таким номером отсутствует в выбранном мессенджере, отправка завершится ошибкой.
3. Каждой линии соответствует отдельный СМС-провайдер.
4. В интерфейсе Битрикс24 может потребоваться нажать «Подробнее», чтобы выбрать конкретный провайдер Олчат среди других.
