# Написать первым из CRM

Ниже описано, как инициировать переписку с клиентом напрямую из Битрикс24 с помощью приложения Олчат ОМНИ.

{% stepper %}
{% step %}
### Открытие приложения

* Откройте карточку сущности в Битрикс24.
* В правой колонке в ленте событий (таймлайн) нажмите «Олчат ОМНИ».
* Дождитесь загрузки — откроется окно отправки сообщения.
{% endstep %}

{% step %}
### Выбор коннектора

В открывшемся окне выберите, от имени которого будет отправлено сообщение.

<figure><img src="../.gitbook/assets/image (1078).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Проверка контакта клиента

Система автоматически подтягивает контакт клиента. Если рядом с контактом отображается **зелёная галочка**, клиент доступен для отправки сообщения через МАКС.

<figure><img src="../.gitbook/assets/image (1079).png" alt=""><figcaption></figcaption></figure>

Если контакт не найден, можно выбрать другой или ввести вручную.
{% endstep %}

{% step %}
### Настройки (шестерёнка)

{% hint style="warning" %}
Настройки доступны после выбора контакта.
{% endhint %}

Под полем для сообщения нажмите значок шестерёнки и настройте параметры:

* **Публиковать в открытую линию** — сообщение уйдёт клиенту и появится в открытой линии от имени оператора.
  *   Если настройка выключена, можно отобразить или скрыть имя оператора.<br>

      <figure><img src="../.gitbook/assets/image (1080).png" alt=""><figcaption></figcaption></figure>
* Ползунок **Создать CRM-активность** — рекомендуется выключить.
{% endstep %}

{% step %}
### Отправка сообщения

* Введите текст сообщения.
* При необходимости прикрепите файл с помощью значка **скрепки** или добавьте шаблон.
* Нажмите кнопку **Отправить**.
{% endstep %}
{% endstepper %}

После отправки сообщение отобразится в ленте событий (в таймлайне) карточки. Если настройка **Публиковать в чате** включена, чат Открытой линии будет создан автоматически.
