# Ожидание ответа

Действие позволяет проверить существование аккаунта в Олчат ОМНИ (МАКС) по различным идентификаторам и получить информацию о пользователе для дальнейшей автоматизации бизнес-процессов.

## Настройка робота

Для проверки наличия аккаунта в Олчат ОМНИ добавьте робота «\[Олчат ОМНИ] \[МАКС] Найти аккаунт»**:** **Роботы → Создать → Выбор стадии → Другие роботы → \[Олчат ОМНИ] \[МАКС] Найти аккаунт → Добавить.**

Параметры настройки:

1. **Линия коннектора** — выберите линию Олчат ОМНИ, через которую будет выполняться поиск.
2. **Тип идентификатора** — выберите один из вариантов:
   * **По ID чата** (внутренний идентификатор).
   * **По номеру телефона.**
3. Остальные параметры можно оставить по умолчанию.
4. Нажмите **Сохранить**.

***

#### Настройка активити (действия) бизнес-процесса

Для использования в бизнес-процессах добавьте действие **«\[Олчат ОМНИ] \[МАКС] Найти аккаунт»**.

**Параметры настройки активити:**

1. **Линия коннектора** — укажите линию Олчат ОМНИ.
2. **Тип идентификатора**.
3. **ID чата / Телефон:** — введите значение для поиска.

Остальные настройки оставьте по умолчанию. Нажмите **Сохранить**.
