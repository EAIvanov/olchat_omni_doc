# Информация об аккаунте

Робот и действие бизнес-процесса «Информация об аккаунте» позволяют автоматически отправлять соответствующие данные в чат мессенджера МАКС.

## Настройка робота

Чтобы добавить робота, перейдите в **Роботы → Создать → Выбор стадии → Другие роботы → \[Олчат ОМНИ] \[МАКС] Информация об аккаунте → Добавить**.

После добавления нажмите **Изменить** и заполните параметры:

1. Линия МАКС — выберите подключенную линию МАКС, через которую будет выполняться отправка.
2. Тип индентификатора.
3. Номер телефона/идентификатор.
4. Сообщение.
5. Публиковать в чате открытой линии?

Остальные параметры можно оставить по умолчанию. Нажмите **СОХРАНИТЬ**.
