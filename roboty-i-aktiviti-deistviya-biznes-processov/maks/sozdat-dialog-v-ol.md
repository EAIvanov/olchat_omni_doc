# Создать диалог в ОЛ

Робот **\[Олчат ОМНИ] \[МАКС] Создать диалог в ОЛ** позволяет создавать новый диалог в Открытой линии для указанного номера телефона или идентификатора клиента в поддерживаемых каналах.

## Настройка робота

Для добавления робота перейдите в **Роботы → Создать → Выбор стадии → Другие роботы → \[Олчат ОМНИ] \[МАКС] Создать диалог в ОЛ → Добавить**.

После добавления нажмите кнопку **Изменить** на роботе, чтобы открыть окно настройки:

1. **Выберите линию.**\
   &#x20;Укажите открытую линию (канал) Олчат ОМНИ, в рамках которой будет создан диалог.
2.  **Номер телефона / Идентификатор клиента.**&#x20;

    Укажите номер телефона или другой идентификатор (username, chat\_id и т.д. в зависимости от канала). Поле поддерживает переменные из CRM (например, \{{Phone\}}, \{{UF\_CRM\_...\}}).
3. **Дополнительные параметры** (при необходимости):
   * **Заголовок диалога** — задайте название чата по шаблону.
   * **Ответственный** — укажите сотрудника, который будет назначен ответственным за диалог.
   * **Источник** — выберите или укажите источник обращения.

Остальные настройки можно оставить по умолчанию. Нажмите кнопку **Сохранить**.

## Настройка активити

Настройка активити практически идентична настройке робота:

1. **Выберите линию.** \
   Укажите открытую линию Олчат ОМНИ.
2. **Тип идентификатора.**\
   Укажите номер или идентификатор клиента (поддерживаются переменные).
3. **Дополнительные параметры**:
   * Текст сообщения.
   * Ответственный.

После заполнения нажмите кнопку **Сохранить**.
