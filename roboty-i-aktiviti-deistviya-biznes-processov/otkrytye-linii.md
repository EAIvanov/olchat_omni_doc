# Открытые линии

Роботы Открытых линий Олчат ОМНИ предназначены для автоматизации работы с диалогами в чатах Открытых линий Битрикс24.

С их помощью можно значительно ускорить и упорядочить обработку обращений: принимать и забирать диалоги в работу, передавать их операторам, завершать обращения, управлять участниками чата и связывать диалоги с сущностями CRM (системы управления взаимоотношениями с клиентами).

## Основное назначение

Роботы выполняются автоматически в рамках настроенных бизнес-процессов Битрикс24. Они срабатывают, когда диалог или связанная с ним сущность (лид, сделка и т.д.) переходит на определённую стадию.

### **Задачи роботов Олчат ОМНИ**

* Автоматизировать распределение обращений между операторами.
* Ускорить принятие и передачу диалогов.
* Упростить завершение и закрытие обращений.
* Поддерживать порядок в чатах (изменение названий, управление участниками).
* Связывать диалоги с нужными сущностями CRM.
* Получать информацию о диалоге для дальнейшей автоматизации.
* Снижать ручную нагрузку на операторов и администраторов Открытых линий.

{% hint style="info" %}
Роботы не заменяют оператора и не предназначены для общения с клиентом. Их задача — выполнять служебные действия вокруг диалога: кто должен принять обращение, куда его передать, как связать с CRM и когда завершить.
{% endhint %}

## Доступные роботы Открытых линий

| Робот                                        | Что делает                                                               | Когда рекомендуется использовать                                                                   |
| -------------------------------------------- | ------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------- |
| **\[ОЛ] Добавить пользователя в чат по CRM** | Добавляет пользователя в чат на основе данных из CRM                     | При необходимости автоматически подключить ответственного или участников из CRM к текущему диалогу |
| **\[ОЛ] Изменить название чата**             | Изменяет название чата, в том числе по шаблону с данными из CRM          | Для поддержания порядка и быстрой идентификации диалогов                                           |
| **\[ОЛ] Управление участниками чата**        | Добавляет или удаляет участников чата                                    | При передаче диалога между отделами или добавлении наблюдателей                                    |
| **\[ОЛ] Закрыть диалоги сущности**           | Закрывает все активные диалоги, связанные с указанной CRM-сущностью      | После завершения сделки или лида                                                                   |
| **\[ОЛ] Информация о диалоге**               | Возвращает подробную информацию о текущем диалоге по идентификатору      | Для использования в сложных сценариях автоматизации                                                |
| **\[ОЛ] Получить чат по CRM**                | Находит и возвращает чат по данным из CRM                                | При необходимости привязать существующий чат к CRM-сущности                                        |
| **\[ОЛ] Принять диалог**                     | Принимает (подключает) оператора к диалогу                               | Автоматическое принятие диалога ответственным сотрудником                                          |
| **\[ОЛ] Завершить диалог**                   | Завершает диалог с указанным статусом                                    | По окончании работы с обращением                                                                   |
| **\[ОЛ] Забрать диалог**                     | Забирает диалог у текущего оператора                                     | При необходимости переназначить диалог                                                             |
| **\[ОЛ] Пропустить диалог**                  | Пропускает диалог (возвращает в очередь)                                 | Когда оператор не может обработать обращение                                                       |
| **\[ОЛ] Пометить как спам**                  | Помечает диалог как спам                                                 | Для фильтрации нежелательных обращений                                                             |
| **\[ОЛ] Управление открытой линией**         | Многофункциональный робот (подключение, закрытие, обработка по условиям) | Для комплексной автоматизации обработки диалогов                                                   |
| **\[ОЛ] Передать диалог**                    | Передаёт диалог другому оператору или линии                              | При эскалации обращения                                                                            |
| **\[ОЛ] Передать на свободного оператора**   | Автоматически передаёт диалог свободному оператору                       | Для равномерного распределения нагрузки                                                            |
