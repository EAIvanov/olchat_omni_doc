# Роботы и активити (действия) бизнес-процессов

{% hint style="info" %}
Статьи в разделе «Роботы и активити» предназначены для специалистов, обладающих практическим опытом настройки роботов и активити бизнес-процессов в Битрикс24. Материал содержит технические детали и требует уверенного понимания принципов интеграции и автоматизации.

При отсутствии соответствующего опыта рекомендуем обратиться к квалифицированному подрядчику или интегратору.
{% endhint %}

## Установка роботов и активити

Включить роботов и активити можно в настройках приложения **Олчат ОМНИ**:

1.  Перейдите в **Настройки приложения**.<br>

    <figure><img src="../.gitbook/assets/image (1098).png" alt=""><figcaption></figcaption></figure>
2. В меню слева выберите раздел **Роботы**.

Для установки нажмите кнопку **Переустановить роботов**. После успешного обновления статус возле каждого робота изменится с неактивного на активный (рядом появится зелёная галочка).

## Описание роботов Олчат ОМНИ

Все перечисленные ниже роботы имеют префикс **\[ОЛ]** и предназначены для работы с Открытыми линиями. Они позволяют автоматизировать управление диалогами, участниками чатов и другие ключевые процессы.

* **\[ОЛ] Добавить пользователя в чат по CRM** — добавляет пользователя в чат на основе данных из CRM.
* **\[ОЛ] Изменить название чата** — изменяет название (заголовок) чата, в том числе по шаблону с использованием параметров из CRM.
* **\[ОЛ] Управление участниками чата** — управляет составом участников чата (добавление, удаление).
* **\[ОЛ] Закрыть диалоги сущности** — закрывает все активные диалоги, связанные с указанной сущностью (лид, сделка и т.д.).
* **\[ОЛ] Информация о диалоге** — получает подробную информацию о текущем диалоге.
* **\[ОЛ] Получить чат по CRM** — находит и возвращает чат по данным из CRM.
* **\[ОЛ] Принять диалог** — принимает (подключает) оператора к диалогу.
* **\[ОЛ] Завершить диалог** — завершает диалог с соответствующим статусом.
* **\[ОЛ] Забрать диалог** — забирает диалог у текущего оператора.
* **\[ОЛ] Пропустить диалог** — пропускает диалог (переводит в очередь).
* **\[ОЛ] Пометить как спам** — помечает диалог как спам.
* **\[ОЛ] Управление открытой линией** — многофункциональный робот для автоматизированной работы с чатами.
* **\[ОЛ] Передать диалог** — передает диалог другому оператору или на другую линию.
* **\[ОЛ] Передать на свободного оператора** — автоматически передает диалог на свободного доступного оператора.

При нажатии на любого робота в интерфейсе Битрикс24 вы можете просмотреть **входные параметры** и **результат** (выходные данные), которые робот возвращает для дальнейшего использования в бизнес-процессах.
