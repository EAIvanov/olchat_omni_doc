# Шорткоды

## Что такое шорткоды

Шорткоды — это специальные текстовые конструкции, с помощью которых можно отправлять различные типы контента через Олчат ОМНИ. Например, шорткод может использоваться для отправки файла, голосового сообщения, контакта или местоположения.

{% hint style="info" %}
Шорткод указывается непосредственно в тексте сообщения в формате: `[=тип:параметры].`
{% endhint %}

Шорткоды можно использовать в:

* Шаблонах сообщений.
* Роботах и активити бизнес-процессов.
* Виджете в карточке CRM (в системе управления взаимоотношениями с клиентами).
* Быстрых ответах в чате Открытой линии.

## Важные особенности для Telegram и МАКС

* Шорткоды работают как в личных чатах, так и в групповых.
* Telegram лучше поддерживает документы и голосовые сообщения.
* При отправке больших файлов рекомендуется использовать прямые ссылки или файлы с Диска.
* Можно комбинировать несколько шорткодов в одном сообщении.
