# Шаблоны сообщений

Приложение Олчат ОМНИ поддерживает использование шаблонов сообщений для каналов Telegram и МАКС. Шаблоны позволяют быстро отправлять однотипные сообщения с автоматической подстановкой данных из CRM (системы управления взаимоотношениями с клиентами).

## Создание шаблонов

Шаблоны сообщений создаются непосредственно в приложении Олчат ОМНИ.

1.  В левом меню перейдите в раздел **Шаблоны сообщений**.<br>

    <figure><img src="../.gitbook/assets/image (1157).png" alt="" width="370"><figcaption></figcaption></figure>
2. Нажмите кнопку **+ Создать шаблон**.

<figure><img src="../.gitbook/assets/image (1160).png" alt=""><figcaption></figcaption></figure>

#### **Заполнение шаблона**

* **Название шаблона** — понятное название для быстрого поиска.
* **Текст сообщения** — введите основной текст шаблона.

Для автоматической подстановки данных нажмите значок **{ }** и выберите нужное поле CRM. Переменные вставляются в формате \{{Название\_поля\}} и автоматически заменяются актуальными значениями при отправке.

* После заполнения текста нажмите **Далее**.

<figure><img src="../.gitbook/assets/image (1161).png" alt=""><figcaption></figcaption></figure>

#### Подготовка шаблона к работе

* Присвойте категорию (опционально).
* Укажите права доступа к шаблону. Если поле оставить пустым, шаблон будет доступен всем сотрудникам.
* Нажмите **Сохранить**.

<figure><img src="../.gitbook/assets/image (1115).png" alt=""><figcaption></figcaption></figure>

## Управление шаблонами

В разделе **Шаблоны сообщений** доступны следующие возможности:

* Поиск по названию и тексту шаблона.
* Фильтрация по категориям.
* Сортировка по столбцам.
* Редактирование и удаление шаблонов.

Для управления категориями нажмите значок шестерёнки **⚙️** в правом верхнем углу.

<figure><img src="../.gitbook/assets/image (1116).png" alt=""><figcaption></figcaption></figure>

## Отправка шаблонов&#x20;

#### Из чата Открытой линии

1. Откройте чат с клиентом.
2.  В поле ввода сообщения нажмите значок **Панель приложений**.<br>

    <figure><img src="../.gitbook/assets/image (1117).png" alt=""><figcaption></figcaption></figure>
3.  В открывшемся окне выберите **Шаблоны Олчат** и нужный шаблон.<br>

    <figure><img src="../.gitbook/assets/image (1156).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
Текст шаблона автоматически вставится в поле ввода, а все переменные подставятся из связанной карточки CRM.
{% endhint %}

### Из карточки CRM

Чтобы отправить шаблон [из карточки сущности](../poluchenie-i-otpravka-soobshenii/napisat-pervym-iz-crm.md#proverka-kontakta-klienta), нужно:

1. Перейти в Олчат ОМНИ в таймлайне справа.
2.  Нажать на **Шаблоны** под полем ввода сообщения.<br>

    <figure><img src="../.gitbook/assets/image (1158).png" alt=""><figcaption></figcaption></figure>
3. Выбрать нужный шаблон из списка.
4. Нажать **Отправить**.

### Из виджета

Чтобы отправить шаблон из виджета, нужно:

1. Перейти к виджету Олчат ОМНИ карточки сущности.
2.  Нажать на **Шаблоны** под полем ввода сообщения.<br>

    <figure><img src="../.gitbook/assets/image (1167).png" alt=""><figcaption></figcaption></figure>
3. Выбрать нужный шаблон из списка.
4. Нажать **Отправить**.

Подстановка данных из CRM происходит только в том случае, если между чатом и соответствующей сущностью CRM (Сделка, Лид, Контакт, Компания) установлена связь.

* Если шаблон содержит переменную, например, \{{Номер\_сделки\}}, система будет искать эту информацию в той сущности, к которой **прикреплён** текущий чат Открытой линии.
* Если чат **не привязан** к нужной сущности (например, чат привязан к Лиду, а переменная берётся из Сделки), значение переменной не подставится — в тексте сообщения останется пустое место или исходный плейсхолдер.

Поэтому результат подстановки зависит от двух факторов:

1. Из какой сущности CRM вы отправляете сообщение (карточка Сделки, Лида и т.д.).
2. К какой сущности прикреплён текущий чат.

{% hint style="info" %}
Перед отправкой шаблона с переменными убедитесь, что чат привязан к нужной карточке CRM. При необходимости привяжите чат вручную или настройте автоматическую привязку через бизнес-процессы.
{% endhint %}

## Рекомендации

* Создавайте понятные и логичные названия шаблонов.
* Группируйте шаблоны по категориям (например: «Приветствия», «Работа с возражениями»).
* Используйте [форматирование текста](../poluchenie-i-otpravka-soobshenii/formatirovanie-teksta.md) внутри шаблонов (жирный, курсив, списки и т.д.) — оно поддерживается с учётом возможностей каждого канала.
* Регулярно тестируйте работу переменных в реальных чатах.
