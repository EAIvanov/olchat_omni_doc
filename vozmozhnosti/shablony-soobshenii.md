# Шаблоны сообщений

Приложение Олчат ОМНИ поддерживает использование шаблонов сообщений для каналов Telegram и МАКС. Шаблоны позволяют быстро отправлять однотипные сообщения с автоматической подстановкой данных из CRM (системы управления взаимоотношениями с клиентами).

## Создание шаблонов

Шаблоны сообщений создаются непосредственно в приложении Олчат ОМНИ.

1. В левом меню перейдите в раздел **Шаблоны сообщений**.
2. Нажмите кнопку **+ Создать шаблон**.

#### **Заполнение шаблона**

* **Название шаблона** — понятное название для быстрого поиска.
* **Текст сообщения** — введите основной текст шаблона.

Для автоматической подстановки данных нажмите значок **{ }** и выберите нужное поле CRM. Переменные вставляются в формате \{{Название\_поля\}} и автоматически заменяются актуальными значениями при отправке.

* После заполнения текста нажмите **Далее**.

#### Подготовка шаблона к работе

* Присвойте категорию (опционально).
* Укажите права доступа к шаблону. Если поле оставить пустым, шаблон будет доступен всем сотрудникам.
* Нажмите **Сохранить**.

## Управление шаблонами

В разделе **Шаблоны сообщений** доступны следующие возможности:

* Поиск по названию и тексту шаблона.
* Фильтрация по категориям.
* Сортировка по столбцам.
* Редактирование и удаление шаблонов.

Для управления категориями нажмите значок шестерёнки **⚙️** в правом верхнем углу.

## Отправка шаблонов&#x20;

#### Из чата Открытой линии

1. Откройте чат с клиентом.
2.  В поле ввода сообщения нажмите значок **Панель приложений**.<br>

    <figure><img src="../.gitbook/assets/image (1117).png" alt=""><figcaption></figcaption></figure>
3. В открывшемся окне выберите **Шаблоны Олчат** и нужный шаблон.

{% hint style="info" %}
Текст шаблона автоматически вставится в поле ввода, а все переменные подставятся из связанной карточки CRM.
{% endhint %}

### Из карточки CRM

Чтобы отправить шаблон из карточки сущности, нужно:

1. Перейти в Олчат ОМНИ в таймлайне справа.
2.  Нажать на **Шаблоны** под полем ввода сообщения.<br>

    <figure><img src="../.gitbook/assets/image (1118).png" alt=""><figcaption></figcaption></figure>
3. Выбрать нужный щаблон из списка.
4. Нажать **Отправить**.

{% hint style="info" %}
Переменные будут автоматически подставлены из данных текущей карточки.
{% endhint %}

## Рекомендации

* Создавайте понятные и логичные названия шаблонов.
* Группируйте шаблоны по категориям (например: «Приветствия», «Работа с возражениями»).
* Используйте [форматирование текста](../poluchenie-i-otpravka-soobshenii/formatirovanie-teksta.md) внутри шаблонов (жирный, курсив, списки и т.д.) — оно поддерживается с учётом возможностей каждого канала.
* Регулярно тестируйте работу переменных в реальных чатах.
