# Виджет на сайт

С помощью виджета на сайте посетитель может перейти в МАКС и написать вашей компании. Обращение поступит в Открытую линию Битрикс24, подключённую к коннектору Олчат ОМНИ.

### Настройка виджета в Олчат ОМНИ

Перейдите в **Олчат ОМНИ → выберите нужный коннектор → Настройки → Виджет на сайт**.

В настройках укажите:

* **Название виджета** — название, которое будет использоваться для канала.
* **Пригласительную ссылку** — ссылку, по которой посетитель сайта сможет перейти в чат.

При необходимости воспользуйтесь ссылкой **Как создать пригласительную ссылку** под соответствующим полем.

<figure><img src="../.gitbook/assets/image (950).png" alt=""><figcaption></figcaption></figure>

После настройки канала его необходимо добавить в виджет Битрикс24.

### Добавление канала в виджет Битрикс24

Перейдите в **CRM → Клиенты → Контакт-центр → Виджет на сайт** и откройте существующий виджет либо создайте новый.

В настройках виджета:

1. Укажите название виджета.
2. В блоке **Каналы, подключенные к виджету** выберите Открытую линию, к которой подключён коннектор Олчат ОМНИ.
3. Включите нужный канал.
4. Сохраните изменения.

Битрикс24 позволяет подключать к одному виджету каналы из разных Открытых линий — для этого используется действие **Добавить открытую линию**.

<figure><img src="../.gitbook/assets/image (952).png" alt=""><figcaption></figcaption></figure>

В правой части страницы можно настроить внешний вид виджета: цвет, положение на странице и время появления. В актуальном интерфейсе Битрикс24 также доступны настройки отображения на мобильных устройствах и другие параметры оформления.

### Как установить виджет на сайт

Если сайт создан в Битрикс24, нужный виджет можно выбрать в настройках сайта.

Для стороннего сайта откройте список виджетов и нажмите **Код на сайт**, скопируйте полученный код и добавьте его в шаблон сайта перед закрывающим тегом `</body>`.

### Как выключить виджет

Выключение самого виджета выполняется **не в настройках коннектора Олчат ОМНИ**.

Перейдите в:

**CRM → Продажи → Каналы продаж → Виджет на сайт.**

Найдите нужный виджет и нажмите **«Выключить»**.

После выключения виджет будет скрыт на всех сайтах, где установлен его код. При повторном включении он снова появится на этих сайтах.

Если требуется убрать виджет только с отдельного сайта или страницы, не выключая его полностью, это можно сделать в настройках самого сайта Битрикс24 либо убрать его код со стороннего сайта.
