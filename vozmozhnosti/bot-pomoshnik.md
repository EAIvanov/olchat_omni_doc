# Бот-помощник

Этот раздел расширяет возможности автоматизации:

* Обновление изображений контактов в CRM (в системе управления взаимоотношениями с клиентами) при добавлении.
* Настройка шаблонов названий чатов.
* Связка параметров аналитики с полями CRM.
* Назначение бота, который будет управлять после основного сценария.
