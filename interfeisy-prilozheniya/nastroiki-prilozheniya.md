# Настройки приложения



Раздел **Настройки приложения** в Олчат ОМНИ — это место, где собраны основные параметры, влияющие на работу всего портала. В отличие от настроек коннектора, эти параметры применяются ко всему приложению.

Чтобы перейти к настройкам, в боковом меню панели Олчат ОМНИ выберите пункт «Настройки приложения».

_\[Скриншот]_

## Структура раздела настроек

Боковое меню настроек включает следующие подразделы:

* Общие — параметры доступа.
* Контакты и уведомления — контактные данные и настройки каналов уведомлений.
* Роботы — управление роботами, установленными в системе.

### Общие

В этом разделе вы можете ограничить доступ к Олчат ОМНИ только для администраторов портала. Активировав опцию «Ограничить доступ только админу», вы сделаете так, чтобы остальные сотрудники не могли открыть приложение — это удобно для защиты данных и внутреннего использования.

При включении ограничения отображается поле для выбора администратора приложения — именно этот пользователь будет иметь полный доступ.

Также в этом разделе можно проверить, под правами какого пользователя работает приложение и назначить другого пользователя.

### Контакты и уведомления

* Контакты для связи.\
  В этом разделе можно указать контактные данные сотрудника, ответственного за настройку приложения
* Каналы уведомлений.\
  &#xNAN;_\[Скриншот выбора каналов]_
* Сотрудники в чате уведомлений Битрикс24.\
  В разделе есть ссылка на переход в чат уведомлений и возможность добавить в этот чат сотрудников.
* История уведомлений.\
  Здесь находятся системные сообщения о работе приложения.

Подробнее об уведомлениях можно узнать [здесь](/broken/pages/JbVST3izEyA0s6RS4jSL).

### Роботы

Раздел **Роботы** содержит список всех роботов и активити бизнес-процессов приложения Олчат ОМНИ и кнопку для их переустановки.

Роботы сгруппированы по типу:

* Открытые линии.
* МАКС.
* МАКС Группы.
* Telegram.
* Telegram Группы.

{% hint style="info" %}
Все настройки сохраняются автоматически. При необходимости вы можете вернуться к этим разделам для внесения корректировок.
{% endhint %}
