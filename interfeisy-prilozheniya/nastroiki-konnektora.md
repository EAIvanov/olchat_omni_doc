# Настройки коннектора

Интерфейс настроек коннектора в приложении Олчат ОМНИ — это инструмент для точной конфигурации обработки сообщений, взаимодействия с CRM (системой управления взаимоотношениями с клиентами) и интеграции различных каналов связи.

## Доступ к настройкам

* Перейдите в приложение Олчат ОМНИ из меню слева.
* В списке выберите нужный аккаунт и нажмите на него.
* Список настроек можно найти в меню слева.

Название коннектора помогает идентифицировать тип и источник подключения.&#x20;

Если к коннектору ранее уже был подключен номер, он отобразится под названием.

### Статус подключения&#xD;

Этот раздел показывает текущий статус выбранного коннектора.

Статус **Подключено** означает, что система успешно интегрирована и работает.

Если коннектор не подключен, вы увидите QR-код, который необходимо отсканировать из приложения на смартфоне, или статус Не подключен. Подробнее в статье [Подключение коннектора](../bystryi-start/podklyuchenie-konnektora.md).

### Чаты&#xD;

Публикация сообщений определяет, каким образом исходящие сообщения из различных источников будут отображаться в открытой линии Битрикс24.

Для каждого источника можно выбрать один из трёх режимов:

| Режим                    | Описание                                         |
| ------------------------ | ------------------------------------------------ |
| **Входящим сообщением**  | Сообщение публикуется как входящее от клиента    |
| **Исходящим сообщением** | Сообщение публикуется как исходящее от оператора |
| **Без публикации**       | Сообщение не отображается в открытой линии       |

Переключатель **Показывать статус «В сети»** управляет видимостью статуса онлайн для подключённого аккаунта. Когда функция включена, аккаунт отображается как «В сети» для других пользователей мессенджера.

**Интервал отправки сообщений** позволяет устанавливать временной промежуток между\
отправляемыми сообщениями. Это полезно для снижения риска блокировки после\
разблокировки во время рассылок через умные сценарии. Доступны интервалы от 0,5\
секунды до 10 минут. Новое значение интервала применяется не сразу, а примерно в\
течение 5 минут. Настройка интервала является общей и распространяется на все\
сообщения, отправляемые через коннектор, в том числе с помощью роботов, маркетинга и\
из карточки CRM.

Также в этом разделе можно настроить взаимодействие с CRM.

**Передавать e-mail для идентификации контакта**

Настройка позволяет Битрикс24 идентифицировать клиентов, поступающих из МАКС, и автоматически связывать обращения с соответствующими контактами в CRM.

Поскольку МАКС не передаёт номер телефона клиента, Олчат формирует служебный e-mail вида \[ID]@max.olchat.ru. Это технический адрес, который не принадлежит клиенту и не используется для переписки.

* Если настройка **включена**, служебный e-mail передаётся в Битрикс24 и используется для поиска/создания контакта.
* Если настройка отключена, такие адреса в Битрикс24 не передаются.

### Группы&#xD;

В этом разделе можно установить режим подключения по умолчанию для различных видов групп и каналов.

* Создавать чаты ОЛ — при создании новых групп система автоматически создаст чат в Открытой линии (в контакт-центре).
* Не создавать чат — группы создаются и работают у вас в приложении.
* Создавать групповые чаты — в Чатах создаются групповые беседы, предназначенные для совместной работы.

### Доступ к коннектору&#xD;

Управляйте правами доступа сотрудников и отделов:

* Назначайте, кто может использовать конкретный коннектор.
*  Если список пуст, доступ есть у всех пользователей системы.

### Вебхук

Используйте вебхуки для автоматической интеграции с внешними системами:

* Отправка данных о событиях (новое сообщение, изменение статуса) по указанному адресу.
* Отлично подходит для синхронизации с CRM, аналитикой или сторонними API (программным интерфейсом).
