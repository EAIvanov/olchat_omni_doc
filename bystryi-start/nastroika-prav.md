# Настройка прав

Настройка прав для работы с приложением Олчат ОМНИ осуществляется в нескольких местах на портале Битрикс24. Для корректной работы необходимо выдать права на само приложение, на просмотр страницы приложения, на настройку открытой линии, на карточку CRM (системы управления взаимоотношениями с клиентами) и на коннектор линии тем сотрудникам, чья работа предполагает использование и настройку приложения.

### Права на коннектор линии <a href="#prava-na-konnektor-linii" id="prava-na-konnektor-linii"></a>

Возможность выбора коннектора для отправки сообщений доступна всем сотрудникам с правами на использование приложения. Доступ можно разграничить для определённых сотрудников или отделов. Чтобы настроить права:

1. Перейдите в приложение **Олчат ОМНИ**.
2. Откройте нужный коннектор в списке и нажмите **Доступ к коннектору** в меню слева.&#x20;
3. Выберите пользователей, отделы или группы и нажмите **ВЫБРАТЬ**.

Для открытия доступа ко всем сотрудникам нажмите **Изменить**, не выбирая пользователей, и нажмите **ВЫБРАТЬ** (список очистится — коннектор станет общедоступным).

### Права на приложение <a href="#prava-na-prilozhenie" id="prava-na-prilozhenie"></a>

{% hint style="info" %}
Если в настройках доступа не указаны пользователи, приложение будет доступно всем сотрудникам. Сотрудники без доступа увидят ошибку при попытке открыть приложение.
{% endhint %}

Доступ к приложению определяется правами в Маркетплейсе Битрикс24:

1.  Перейдите в раздел **Приложения** → **Маркетплейс**. В верхнем меню выберите **Ещё** → **Установленные приложения**. <br>

    <figure><img src="../.gitbook/assets/image (1110).png" alt=""><figcaption></figcaption></figure>
2.  Найдите приложение Олчат ОМНИ в списке установленных. Нажмите на три точки (**...**) на карточке приложения и выберите пункт **Доступ**. <br>

    <figure><img src="../.gitbook/assets/image (1111).png" alt=""><figcaption></figcaption></figure>
3.  Определите, какие пользователи или отделы могут видеть и использовать приложение Олчат, и нажмите **Выбрать**.<br>

    <figure><img src="../.gitbook/assets/image (1112).png" alt=""><figcaption></figcaption></figure>

### Права на открытые линии <a href="#prava-na-otkrytye-linii" id="prava-na-otkrytye-linii"></a>

Для работы с чатами мессенджеров сотрудник должен быть добавлен в очередь соответствующей открытой линии:

1. Перейдите в CRM (в систему управления взаимоотношениями с клиентами) → **Клиенты** → **Контакт-центр** → карточка \[Олчат] МАКС/Telegram → выберите Открытую линию → **Настройки открытой линии и прав доступа** → **Настроить**.
2. В списке выберите ответственных сотрудников.
3. Сохраните изменения.
4. Затем определите права доступа для ролей и сотрудников.
5. Изменения сохраняются автоматически.

<figure><img src="../.gitbook/assets/image (1113).png" alt=""><figcaption></figcaption></figure>

### Права на карточку CRM <a href="#prava-na-kartochku-crm-sistemy-upravleniya-vzaimootnosheniyami-s-klientami" id="prava-na-kartochku-crm-sistemy-upravleniya-vzaimootnosheniyami-s-klientami"></a>

Виджеты Олчат ОМНИ в карточке контакта, сделки или лида («Написать первым», шаблоны сообщений) доступны автоматически всем пользователям, у которых есть доступ к соответствующим сущностям CRM.Чтобы настроить права:

*   Перейдите в **CRM → Настройки → Права доступа к CRM**. <br>

    <figure><img src="../.gitbook/assets/image (1114).png" alt=""><figcaption></figcaption></figure>
* Добавьте или отредактируйте роль, установите нужные права на изменение клиента/сделки и сохраните.

### Права на просмотр страницы приложения <a href="#prava-na-prosmotr-stranicy-prilozheniya" id="prava-na-prosmotr-stranicy-prilozheniya"></a>

Право на просмотр страницы приложения и управление его настройками выдаётся только администраторам или всем сотрудникам портала. Перейдите в **Олчат ОМНИ → Настройки приложения → Общие** и включите/выключите ползунок «Показывать страницу приложения только администраторам».

### Установка прав администратора на приложение <a href="#ustanovka-prav-administratora-na-prilozhenie" id="ustanovka-prav-administratora-na-prilozhenie"></a>

{% hint style="info" %}
Иногда возникает ситуация, когда сотрудника, установившего приложение Олчат, необходимо уволить с портала Битрикс24. Перед этим рекомендуем поменять права на другого пользователя.
{% endhint %}
