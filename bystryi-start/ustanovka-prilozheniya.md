# Установка приложения

Ниже описан процесс установки и первоначальной настройки приложения Олчат ОМНИ в Битрикс24. Рекомендуется использовать актуальную версию Битрикс24.

## Шаги по установке

### Установка из магазина приложений

1.  Перейдите в **Маркетплейс** Битрикс24.\
    Войдите в ваш портал Битрикс24, в верхнем меню выберите раздел **Маркетплейс**.<br>

    <figure><img src="../.gitbook/assets/image (11).png" alt=""><figcaption></figcaption></figure>
2. Найдите приложение. \
   В поисковой строке введите **Олчат ОМНИ**.
3.  Установите приложение.\
    Откройте страницу приложения и нажмите кнопку **Установить**. Ознакомьтесь с условиями использования, лицензионным соглашением, политикой конфиденциальности и подтвердите установку.<br>

    <figure><img src="../.gitbook/assets/image (12).png" alt=""><figcaption></figcaption></figure>
4. Завершение установки.  \
   После успешной установки приложение появится в левом меню вашего портала Битрикс24. Заполните данные, поставьте галочку согласия на обработку персональных данных и нажмите кнопку сохранения.

{% hint style="info" %}
Этот этап можно пропустить — просто нажмите на крестик в правом верхнем углу экрана. Вы сможете вернуться к заполнению данных позже.

Обращаем ваше внимание, что контактная информация помогает нам связаться с вами в случае необходимости, поэтому рекомендуем указать её как можно скорее.
{% endhint %}

Приложение готово к дальнейшей настройке. В левом меню теперь доступен раздел **Олчат ОМНИ**.&#x20;

### Установка по прямой ссылке <a href="#ustanovka-po-pryamoi-ssylke" id="ustanovka-po-pryamoi-ssylke"></a>

Перейдите по [ссылке](https://www.bitrix24.ru/apps/app/infocom.olchat_omni/). Откроется окно установки сразу на шаге 4 — заполните контактные данные и завершите установку.

### Дополнительные настройки для коробочной версии Битрикс24

Если вы используете коробочную версию, дополнительно откройте сетевые доступы к серверам согласно [рекомендациям технической поддержки](dopolnitelnye-nastroiki-dlya-korobochnoi-versii-bitriks24.md) Олчат.
