# Подключение коннектора

Коннектор — это связующее звено между мессенджером и открытой линией Битрикс24. После подключения коннектора сообщения из мессенджера автоматически поступают в чаты Битрикс24, а ответы операторов отправляются обратно клиенту.

Коннектор **Олчат ОМНИ** обеспечивает двустороннюю связь:

* Входящие сообщения из мессенджера поступают в открытую линию Битрикс24, где их обрабатывают операторы.
* Исходящие сообщения от операторов из Битрикс24 отправляются клиенту в мессенджер.

**Олчат ОМНИ** поддерживает два мессенджера:

* **Telegram** — личные и групповые чаты через аккаунт Telegram.
* **МАКС** — личные и групповые чаты через аккаунт МАКС.

## Подключение коннектора

Для подключения коннектора выполните следующие действия:

1. Перейдите в раздел **Приложения** в левом меню Битрикс24 и выберите **Олчат ОМНИ**.&#x20;
2.  На панели приложения слева  выберите мессенджер, который необходимо подключить (Telegram или МАКС).<br>

    <figure><img src="../.gitbook/assets/image (1081).png" alt=""><figcaption></figcaption></figure>
3.  В выпадающем списке выберите открытую линию Битрикс24, к которой будет привязан коннектор. Если у вас ещё нет открытой линии, создайте её.

    <div data-gb-custom-block data-tag="hint" data-style="info" class="hint hint-info"><p>К одной открытой линии можно подключить разные коннекторы (например, один аккаунт Telegram + один аккаунт МАКС). Каждый коннектор оплачивается отдельно.<br>Однако если вам нужно подключить несколько аккаунтов Telegram или несколько аккаунтов МАКС, создайте для каждого отдельную открытую линию.</p></div>
4.  Нажмите кнопку Подключить. Система привяжет выбранный мессенджер к открытой линии.

    <figure><img src="../.gitbook/assets/image (1082).png" alt=""><figcaption></figcaption></figure>

После этого потребуется авторизовать аккаунт мессенджера. Процесс авторизации отличается для каждого мессенджера:

* Для [Telegram](../akkaunty-i-avtorizaciya/avtorizaciya-telegram.md).
* Для [МАКС](../akkaunty-i-avtorizaciya/avtorizaciya-maks.md).

## Проверка подключения

После успешного подключения и авторизации:

* Статус коннектора на панели приложения изменится на **Подключено**.
* Входящие сообщения из мессенджера начнут поступать в чаты Битрикс24.

{% hint style="info" %}
Рекомендуем отправить тестовое сообщение в подключённый аккаунт мессенджера, чтобы убедиться, что сообщения корректно поступают в Битрикс24.
{% endhint %}

## Подключение нескольких коннекторов

Приложение **Олчат ОМНИ** позволяет подключить несколько коннекторов к одному порталу Битрикс24:

* Несколько аккаунтов Telegram на разных открытых линиях.
* Несколько аккаунтов МАКС на разных открытых линиях.
* Комбинацию коннекторов Telegram и МАКС.

Каждый коннектор привязывается к отдельной открытой линии с собственной очередью операторов и настройками.

{% hint style="warning" %}
Каждая открытая линия имеет собственную очередь операторов и настройки. Если с Telegram должны отвечать одни менеджеры, а с МАКС — другие, подключите их к разным открытым линиям.
{% endhint %}
