# Тарифы

## Демо-период

Всем новым пользователям предоставляется бесплатный пробный период 7 дней.

После установки приложения вам сразу доступны все  возможности для тестирования. Демо-период активируется автоматически при подключении первой линии.&#x20;

## Стоимость лицензии

Единый тариф: 3600 ₽ за 30 дней за одну линию.

Одна лицензия позволяет использовать одну открытую линию. Оплаченный период суммируется к уже имеющимся дням.

## Способы оплаты

* **Банковской картой** — самостоятельно прямо на странице выставленного счёта.
* **По счёту** (включая оплату через СБП) — через специалистов поддержки.

{% hint style="warning" %}
Пока самостоятельно сформировать счёт в личном кабинете невозможно. Для получения счёта на оплату обращайтесь в поддержку — специалисты подготовят все документы в кратчайшие сроки.
{% endhint %}
